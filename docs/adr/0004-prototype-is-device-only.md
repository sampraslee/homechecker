# The prototype keeps all data on the Inspector's phone

The blueprint describes a cloud backend with sync, object storage and an Office/Admin web app. The first build is a prototype for testing with Inspectors only, so it has no server: Inspections, Defects and Evidence (including full-resolution originals) live only on the device, and data leaves the phone via export. The accepted costs: a lost or wiped phone loses its Inspections, and a Move-out can only be linked to a Move-in recorded on the same phone. Sync, the web app, user accounts and cloud storage are deferred, not dropped.
